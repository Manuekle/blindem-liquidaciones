# Hugeicons

Version: 4.4.0 of the official `@hugeicons/core-free-icons` npm package, Stroke Rounded style (free).

Only the icons used by the app are included in ../hugeicons.svg, with each symbol's source icon noted in a comment. Symbol ids are the app's own names (`trash-2`, `users-round`…), so views and scripts keep using `#name`. Stroke color, width and caps come from the app CSS; the standalone check, chevron-down and circle-alert files are CSS masks and backgrounds. No runtime package or CDN is required. See LICENSE.md.

Source: https://registry.npmjs.org/@hugeicons/core-free-icons/-/core-free-icons-4.4.0.tgz
Catalog: https://hugeicons.com/icons
