# Lucide icons

Version: 1.64.0, from the official lucide-static npm package.

Only the icons used by the app are included in ../lucide.svg. The standalone check and chevron-down files are used as CSS masks/backgrounds. No runtime package or CDN is required. See LICENSE.

Source: https://registry.npmjs.org/lucide-static/-/lucide-static-1.64.0.tgz
Documentation: https://lucide.dev/guide/static
